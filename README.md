# Paulo Martins — Portfolio

Personal portfolio focused on the intersection of **Supply Chain, Analytics and Digital Product Development**.

## Stack

- React
- TypeScript
- Vite
- GitHub Pages

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run typecheck
npm run build
```

## Content

The portfolio is bilingual (pt-BR/en) and presents:

- Supply Chain, S&OP/S&OE, DDMRP and planning experience;
- analytics and BI work;
- StockHub and DemandHub as selected digital-product case studies;
- an AI-assisted, specification- and validation-driven product-development workflow.

Public portfolio content intentionally avoids publishing confidential corporate data or private source code.

## Deployment

`main` is configured to build and deploy the static site through GitHub Actions to GitHub Pages. Vite uses `/portfolio/` as the production base path for the project-site URL.
